# BioStream MCP Server - 보안 아키텍처 다이어그램

## 전체 시스템 아키텍처

```
┌─────────────────────────────────────────────────────────────────┐
│                         클라이언트 앱                             │

└────────────────────┬────────────────────────────────────────────┘
                     │ OAuth 2.1 Token
                     ▼
┌─────────────────────────────────────────────────────────────────┐
│                      MCP 서버 (server_secure.py)                 │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │                    보안 미들웨어 계층                         │ │
│ └─────────────────────────────────────────────────────────────┘ │
│                                                                   │
│ ┌──────────────┐  ┌──────────────┐  ┌──────────────┐          │
│ │ 인증/권한    │  │ 데이터 보호  │  │ 감사/모니터링│          │
│ │ (auth.py)    │  │ (data_      │  │ (audit.py)   │          │
│ │              │  │  protection)│  │              │          │

## 보안 플로우 다이어그램

```
사용자 요청
    │
    ▼
┌────────────────────────────────────┐
│ 1. OAuth 토큰 검증                  │
│    - JWT 디코딩                     │
│    - 만료 확인                      │
│    - 폐기 여부 확인                 │
└────────────┬───────────────────────┘
             │ ✓ 유효한 토큰
             ▼
┌────────────────────────────────────┐
│ 2. RBAC/ABAC 권한 확인              │
│    - 역할 검증 (FREE/PREMIUM/ADMIN) │
│    - 스코프 확인                    │
│    - 속성 기반 정책 평가            │
└────────────┬───────────────────────┘
             │ ✓ 권한 있음
             ▼
┌────────────────────────────────────┐
│ 3. 사용자 동의 확인                 │
│    - 기존 동의 조회                 │
│    - 필요시 새 동의 요청            │
│    - 자동 승인 조건 확인            │
└────────────┬───────────────────────┘
             │ ✓ 동의 확인
             ▼
┌────────────────────────────────────┐
│ 4. 속도 제한 확인                   │
│    - 분당 요청 수 확인              │
│    - 데이터 볼륨 확인               │
└────────────┬───────────────────────┘
             │ ✓ 제한 내
             ▼
┌────────────────────────────────────┐
│ 5. 이상 징후 탐지                   │
│    - 과도한 요청 확인               │
│    - 권한 외 접근 시도              │
│    - 야간 접근 확인                 │
└────────────┬───────────────────────┘
             │ ✓ 정상 패턴
             ▼
┌────────────────────────────────────┐
│ 6. Human-in-the-Loop (고위험만)     │
│    - 위험도 평가                    │
│    - 사용자 승인 대기               │
└────────────┬───────────────────────┘
             │ ✓ 승인 완료 또는 저위험
             ▼
┌────────────────────────────────────┐
│ 7. 도구 검증 (Guardrails)           │
│    - Pydantic 스키마 검증           │
│    - 파라미터 범위 확인             │
│    - 제약 조건 평가                 │
└────────────┬───────────────────────┘
             │ ✓ 검증 통과
             ▼
┌────────────────────────────────────┐
│ 8. 데이터 조회                      │
│    - 데이터베이스 쿼리              │
│    - 원본 데이터 획득               │
└────────────┬───────────────────────┘
             │
             ▼
┌────────────────────────────────────┐
│ 9. 데이터 보호 파이프라인           │
│    ┌──────────────────────────┐   │
│    │ 9-1. PII 마스킹           │   │
│    │   - 이메일 마스킹         │   │
│    │   - 전화번호 마스킹       │   │
│    └──────────┬───────────────┘   │
│               ▼                    │
│    ┌──────────────────────────┐   │
│    │ 9-2. 데이터 최소화        │   │
│    │   - 필요 필드만 선택      │   │
│    │   - 시간 범위 제한        │   │
│    └──────────┬───────────────┘   │
│               ▼                    │
│    ┌──────────────────────────┐   │
│    │ 9-3. 요약 (선택사항)      │   │
│    │   - 통계 계산             │   │
│    │   - 점수화                │   │
│    └──────────────────────────┘   │
└────────────┬───────────────────────┘
             │
             ▼
┌────────────────────────────────────┐
│ 10. 감사 로그 기록                  │
│     - Tool Call 상세 기록           │
│     - 타임스탬프, 사용자 ID         │

└────────────┬───────────────────────┘
             │
             ▼

```

    │
    ▼

           ▼
┌───────────────────────────────────┐
│  규칙 평가                         │

│            │ YES → 🚫 차단       │

│  ┌─────────────────────────────┐ │
│  │ 야간 접근?                   │ │
│  │ 02:00-05:00 접근             │ │

             │
             ▼
       정상 처리 계속
```

## 모듈별 책임

```
┌────────────────────────────────────────────────────────────┐
│  auth.py - 인증 및 권한 부여                                │
├────────────────────────────────────────────────────────────┤
│  • SecurityManager: 통합 보안 관리                          │
│  • TokenValidator: JWT 검증 및 생성                         │
│  • RBACPolicy: 역할 기반 권한                               │
│  • ABACPolicy: 속성 기반 권한                               │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│  data_protection.py - 데이터 보호                           │
├────────────────────────────────────────────────────────────┤
│  • PIIMasker: 개인정보 마스킹                               │
│  • DataMinimizer: 데이터 최소화                             │
│  • EncryptionManager: 암호화/복호화                         │
│  • DataProtectionPipeline: 통합 파이프라인                  │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│  audit.py - 감사 및 모니터링                                │
├────────────────────────────────────────────────────────────┤
│  • AuditLogger: Immutable 로그                              │
│  • AnomalyDetector: 이상 징후 탐지                          │
│  • EventType, EventSeverity: 이벤트 분류                    │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│  consent.py - 사용자 동의 및 제어                           │
├────────────────────────────────────────────────────────────┤
│  • ConsentManager: 동의 관리                                │
│  • HumanInTheLoopValidator: HITL 검증                       │
│  • ConsentRequest, ConsentRecord: 동의 모델                 │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│  guardrails.py - 도구 검증 및 Sandboxing                    │
├────────────────────────────────────────────────────────────┤
│  • SemanticGuardrails: 의미론적 제약                        │
│  • ToolValidator: Pydantic 검증                             │
│  • RateLimiter: 속도 제한                                   │
│  • ToolMetadata: 도구 메타데이터                            │
└────────────────────────────────────────────────────────────┘
```
